# 📘 Guía para Colaboradores - Proyecto Patitas Felices

Para integrarse y colaborar de forma segura en este proyecto, los desarrolladores deben seguir el siguiente flujo de trabajo estandarizado:

1. **Clonar el repositorio:** Descargar el proyecto localmente ejecutando:
  
   git clone https://github.com/ronnyjejeje-bit/proyecto-veterinaria.git

2. **Crear ramas de trabajo:** Nunca trabajar directamente en master. Para cada nueva tarea o característica, crear una rama aislada con:

git checkout -b feature/[nombre-tarea]
3.   **Realizar commits:** Tras probar los cambios locales, registrar el progreso utilizando convenciones claras:

git add .
git commit -m "tipo: descripción clara del cambio"
4.  **Sincronizar: Subir la rama al repositorio remoto con:**

git push origin feature/[nombre-tarea]
5. **Integración: Crear un Pull Request (PR) en GitHub y solicitar la revisión del otro miembro del equipo antes de fusionar el código en la rama principal.**
